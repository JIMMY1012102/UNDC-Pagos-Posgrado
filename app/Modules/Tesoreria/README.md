# Conciliación y Tesorería

Propietario de seis tablas: `tienda_lotes_conciliacion`, `tienda_detalles_conciliacion`, `tienda_validaciones_pago`, `tienda_constancias_validacion`, `tienda_vinculos_sistemas_externos`, `tienda_eventos_auditoria`.

La BD prepara conciliación, validaciones y auditoría, pero la funcionalidad institucional es pendiente. No publicar rutas administrativas ni modificar `tm_*` sin autorización OTI/Tesorería.
