# Catálogo

Responsable de `store_office_settings`, `store_catalog_items`, `store_catalog_price_versions`. Ofrece lectura de publicaciones y contrato `CatalogItemLookup` a Pedidos. El adaptador de SISPAGOS lee las oficinas y conceptos institucionales sin duplicarlos ni modificarlos. La existencia de `tm_conceptos.costo` no equivale a una tarifa de checkout aprobada.
