# Base de datos

El proyecto conserva las migraciones iniciales de Laravel; las tablas del negocio de Posgrado y las de SISPAGOS **no se han incorporado**. Existe un diseño SQL local trabajado por separado y pendiente de revisión/integración. Antes de crear migraciones de la tienda: validar entidades, columnas, relaciones, restricciones, históricos y compatibilidad con Tesorería. Usar solo base de desarrollo con datos ficticios; no migrar producción institucional automáticamente.
